OpenInsert 0.3.0 adds a compact green waveform, switchable English and Traditional Chinese interfaces, and recorded custom shortcuts. These are the changes since the latest public release, 0.2.7; the waveform work previously existed only in the unreleased 0.2.8.

- **Compact green waveform:** microphone volume appears as dense green bars above the transcript in a narrower, screen-adaptive floating panel. Silence does not produce artificial movement. Reduce Motion is respected; simulated movement is limited to the explicitly labelled, microphone-free preview. The panel still hides immediately after paste dispatch.
- **English / 繁體中文 interface:** switch languages without restarting. The main window, menu, floating panel, shortcut recorder, status messages and errors update together. The preference persists across launches and stays separate from ASR detection, writing-language preferences and transcript content. Existing users retain Traditional Chinese by default. Translation tables use an extensible resource structure with English fallback; see the [localization guide](https://github.com/Buffett111/OpenInsert/blob/v0.3.0/docs/LOCALIZATION.md).
- **Record a custom shortcut:** in Preferences, press a combination, review it and save. Ordinary keys require Command, Option or Control; F1–F20 may be used alone. The app saves the setting only after global registration succeeds. Conflicts leave the saved setting unchanged, and Escape or cancellation restores the previous shortcut. Option + Space remains the default, and existing preset settings migrate automatically. Shortcut recording reads events only in the foreground recorder sheet; it adds no global keyboard monitor or Input Monitoring permission.

**Verified:** 123 XCTest cases passed, including localization-resource parity, format arguments, fallback, packaged-resource loading, shortcut migration and validation. Native Carbon checks covered registration conflicts and preservation of the previous registration. The installed 0.3.0 UI was tested in both languages, with custom-shortcut save, Escape cancellation and persistence after restarting. The tested local update preserved the API key, consent and microphone/Accessibility access. Universal builds, code-signature checks and the existing synthetic PCM checks passed; the waveform also passed offline layout checks at multiple widths and in light/dark appearance. See the [validation report](https://github.com/Buffett111/OpenInsert/blob/v0.3.0/docs/VALIDATION.md) for the evidence and its scope.

**Not yet verified for 0.3.0:** a fresh end-to-end session using a real microphone and Google, the new waveform's response to actual microphone input, every custom shortcut's physical hold/tap behavior, all keyboard layouts, or every destination app. Earlier successful dictation tests on 0.2.6/0.2.7 do not establish those new results. Intel is cross-compiled, not tested on an Intel Mac.

Text delivery keeps the existing guarded Command-V path and persistent automatic-copy fallback. A paste request has no OS delivery receipt; normal clipboard restoration still checks ownership after 800 ms. Gemini models, cloud consent and audio handling are unchanged. Your key stays in Keychain, audio goes directly to Google, and there is no OpenInsert account, developer backend, screen capture or transcript-history database. Clipboard copies may remain or sync through clipboard managers and system features.

**Download:** universal Apple Silicon/Intel builds for macOS 13 or later. This remains an **ad-hoc-signed, unnotarized community prerelease**, not a Developer ID release. macOS may block the download or require Accessibility to be granted again after replacing a differently signed copy. Use your own Gemini API key and read [installation](https://github.com/Buffett111/OpenInsert/blob/v0.3.0/docs/INSTALL.txt), [privacy](https://github.com/Buffett111/OpenInsert/blob/v0.3.0/docs/PRIVACY.md) and the validation report before use. Release publication and downloaded-asset verification are tracked separately; passing source tests does not by itself verify the release archives.
