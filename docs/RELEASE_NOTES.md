OpenInsert 0.2.7 improves ChatGPT/Codex input compatibility, keeps completed dictation available when automatic insertion cannot proceed, and clears the floating panel promptly after paste dispatch.

- **Promptly dismiss the floating panel:** after sending the paste request, hide the panel immediately instead of covering the editor during the clipboard restoration delay or showing a two-second technical completion message. Automatic-copy notices remain visible for six seconds and errors for ten seconds.
- **Automatic clipboard copy:** if a finalized result has no valid input target or a supported failure occurs before paste dispatch, copy it persistently so Command-V works without reopening OpenInsert. Clipboard ownership/read/write failures, cancellation, interim-only results and blocked provider failures do not trigger another write.
- **ChatGPT/Codex compatibility:** initialize Accessibility using actual capabilities, including a narrow Chromium application-class fallback, then verify the original app and input before one standard Command-V request. The user confirmed spoken dictation directly into the affected input on 0.2.6; 0.2.7 preserves that path and changes when the panel hides.
- **Multilingual code-switching:** preserve the languages spoken, with editable writing-language preferences. The app is not restricted to Traditional Chinese and English.
- **Avoid duplicate Spotlight entries from development builds:** keep working app bundles and temporary DMG contents in hidden build staging. Public ZIP, DMG and SHA-256 files stay in `dist`.

The API key remains in Keychain. Audio goes directly to Google with the user's consent; there is no OpenInsert account, developer backend, screen capture or transcription history. Clipboard copies may be retained or synced by clipboard managers and system features.

**Validation:** both 0.2.7 GitHub workflows passed 105 XCTest cases, 15 synthetic PCM checks and universal builds. The downloaded release ZIP and DMG passed SHA-256 and archive checks; the extracted app passed strict code-signature verification and contains arm64 and x86_64 binaries, version 0.2.7/build 9. The local 0.2.7 installation preserved the API key and permissions, and the user confirmed that the floating panel disappears immediately after dictation inserts into ChatGPT. Automatic clipboard copy/paste passed a fixed-sentence test on the preceding 0.2.6. Version-specific results are recorded in the [validation report](VALIDATION.md). This does not establish every editor, restart scenario or dictation gesture. A paste request has no OS delivery receipt, and normal clipboard restoration still checks ownership after 800 ms.

**Download:** universal Apple Silicon/Intel binaries for macOS 13 or later. This is an **ad-hoc-signed, unnotarized prerelease**, not a Developer ID release. Use your own Gemini API key. Read [installation](INSTALL.txt), [privacy](PRIVACY.md) and the validation report before use.
