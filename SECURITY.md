# Security and privacy reports

Do not include API keys, recordings, clipboard data, or private transcripts in public reports. Report a minimal reproduction using synthetic data. Until private vulnerability reporting is enabled, open an issue asking for a private contact channel without publishing exploit details or secrets.

OpenInsert has no backend and cannot revoke a Google key for you. If a key is exposed, revoke it in Google AI Studio. Deleting the app does not remove its Keychain entry; use the app's Delete key button first. See docs/PRIVACY.md for storage and transmission details.
